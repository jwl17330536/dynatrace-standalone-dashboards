# Dynatrace Assist — Operator Utilization & Cost

Tracks usage and cost for Dynatrace Assist's Operator skill — showing which users are sending the most prompts, how much data is being billed, and how conversation sessions are distributed across users. Useful for platform teams managing AI assistant costs.

## What it shows

- Top users by prompts sent
- Top users by billed bytes (GB)
- Billed bytes by data type
- User cost and activity summary
- Conversation sessions (Operator Skill)
- Recent conversations (Operator Skill)

## Pre-requisites

- **Dynatrace Assist** (Operator skill) enabled in your environment
- **Grail** enabled for DQL queries on Assist usage data

## How to import

1. Open your Dynatrace tenant
2. Go to **Dashboards** → **Import**
3. Upload the `.json` file from this folder
4. The dashboard opens immediately
