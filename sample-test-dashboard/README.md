# Sample Test Dashboard

A minimal dashboard used to test the [DT Community Assets](https://oei3894h.sprint.apps.dynatracelabs.com/ui/apps/my.dt.community.assets) import flow.

## What it shows

- A markdown banner confirming the import worked
- Host count (single-value tile)
- Active problem count (single-value tile)

## Pre-requisites

- Dynatrace tenant with Grail enabled
- OneAgent or entity data present (host count tile will show 0 otherwise — that's fine for testing)

## How to import

1. Open the **DT Community Assets** Hub App
2. Go to **Settings** and add `jwl17330536/dynatrace-standalone-dashboards`
3. Find **Sample Test Dashboard** in the catalog
4. Click **Import Dashboard**
