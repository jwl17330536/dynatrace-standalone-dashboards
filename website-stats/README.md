# Website Stats

Simple raw log view for a self-hosted website, surfacing the underlying log records for manual inspection and ad-hoc analysis.

## What it shows

- Raw log records from the web server

## Pre-requisites

- **Log Monitoring / Grail** enabled
- Web server logs forwarded to Dynatrace

## How to import

1. Open your Dynatrace tenant
2. Go to **Dashboards** → **Import**
3. Upload the `.json` file from this folder
4. The dashboard opens immediately
